# 09. リリース前の手動検証チェックリスト

自動テストでは確認できない項目(実際の画像生成、画面操作、インストーラ、OS 固有の挙動)を、**リリース前に Windows 11 と macOS の実機で**確認する。
GitHub Releases の下書きを公開する前に、すべての項目を確認し、結果を §12 に記録すること。

> ステータス: 🟢 承認済み(2026-11-19)

## 0. 事前条件

- [ ] `develop` の対象コミットで **CI が成功**している(`check` と `bundle`)。
- [ ] バージョンを更新した(`package.json` / `src-tauri/Cargo.toml` / `src-tauri/tauri.conf.json`)。`node tools/check-version.mjs` が通る。
- [ ] タグ `vX.Y.Z` を push し、`release.yml` が **下書き** のリリースを作った。
- [ ] 検証用の ComfyUI を用意した(`npm run comfyui:setup` / `start`、または公式ポータブル版)。
- [ ] 検証用のモデルを配置した(下表)。ライセンス(特に Flux.1 dev は非商用)を確認した。

| 検証対象 | 必要なモデル(例) |
|---|---|
| SDXL | チェックポイント 1 つ(`models/checkpoints/`) |
| Flux GGUF | GGUF の拡散モデル(`models/unet/`)、T5 と CLIP-L(`models/clip/`)、`ae.safetensors`(`models/vae/`)。ComfyUI-GGUF ノード |
| Flux(通常) | `models/unet/` に safetensors、同上のテキストエンコーダと VAE |

検証環境: Windows 11(NVIDIA GPU)/ macOS(Apple Silicon、メモリ 16GB 以上)。

## 1. インストール・起動

- [ ] 下書きリリースのインストーラをダウンロードして実行できる。
  - Windows: SmartScreen の警告(未署名)を「詳細情報 → 実行」で進められる。管理者権限を求められない。
  - macOS: `.dmg` を開き、`/Applications` へコピーできる。初回は Gatekeeper の警告が出る(macOS 15 以降は「システム設定 → プライバシーとセキュリティ → このまま開く」。それ以前は右クリック → 開く)。「壊れているため開けません」と出る場合は署名の不具合(`codesign --verify --deep --strict` で確認)。
- [ ] アプリが起動し、ウィンドウが表示される(白画面でない)。最小サイズ(960×640)より小さくできない。
- [ ] 日本語の UI が表示される。OS のロケールが英語なら英語になる。
- [ ] データ保存先が作られる。
  - Windows: `%APPDATA%\dev.gazoo.desktop\`(`gazoo.db`、`images\`)/ ログ: `%LOCALAPPDATA%\dev.gazoo.desktop\logs\`
  - macOS: `~/Library/Application Support/dev.gazoo.desktop/` / ログ: `~/Library/Logs/dev.gazoo.desktop/`

## 2. ComfyUI 接続

- [ ] ComfyUI を **停止した状態**で起動 → サイドバーが「ComfyUI 未接続」(赤)、生成画面にバナーが出る。生成ボタンが無効。
- [ ] ComfyUI を起動 → 約 5 秒以内にバッジが緑になり、バナーが消える。
- [ ] ComfyUI を停止 → 約 5 秒以内に未接続になる(アプリを再起動せずに)。
- [ ] 設定で別の URL(存在しないポート)を保存 → 未接続になり、元の URL に戻すと接続される。「再接続」ボタンが効く。
- [ ] http でも https でない URL(`ftp://…`)は保存時にエラー表示される。

## 3. 生成(SDXL)

- [ ] モデル種別 SDXL を選ぶと、チェックポイントの一覧が出て、先頭が自動選択される。
- [ ] プロンプトを入力して「生成」(または `Ctrl/⌘ + Enter`)→ 進捗バーが進み、完了すると画像が表示される。
- [ ] 画像が `images/YYYY/MM/<id>.png` に保存され、サムネイルが `images/thumbs/` に作られる。
- [ ] 枚数 3 で生成 → キューに 3 件が順に実行される(シードがランダム / 固定なら +1 ずつ)。
- [ ] 実行中に「キャンセル」(または `Esc`)→ 取り消され、次のジョブへ進む。ComfyUI 側も中断されている。
- [ ] 待機中ジョブの並べ替え(上へ / 下へ)が、実行順に反映される。待機中のキャンセルができる。
- [ ] 存在しないモデルが選ばれた状態で生成 → 「モデルが見つかりません」と表示され、モデル一覧が更新される。
- [ ] 失敗したジョブを「再試行」できる。
- [ ] (可能なら)大きすぎる解像度で生成 → メモリ不足の失敗に、解像度を下げるヒントが出る。

## 4. 生成(Flux)

- [ ] 種別 Flux.1 (GGUF) → モデル、T5、CLIP-L、VAE が自動選択される。ネガティブ入力が非表示で、CFG の代わりに Guidance が出る。
- [ ] ComfyUI-GGUF が **未導入** の ComfyUI では、警告が出る。
- [ ] 生成が完了し、画像が表示される。
- [ ] (Mac 16GB)量子化モデルで、メモリ逼迫・極端な低速にならずに完了する。

## 5. ギャラリー

- [ ] 生成した画像が一覧に出る。サムネイルが表示される(壊れた画像アイコンになっていない)。
- [ ] 画像をクリック → 詳細パネル(原寸、パラメータ)。プロンプト・シードのコピーができる。
- [ ] 「この設定で生成」→ 生成画面に設定とシードが復元され、同じ設定で再生成すると **同じ画像** になる(同一環境・同一モデル)。
- [ ] お気に入りの切り替え。「お気に入りのみ」で絞り込める。
- [ ] 検索(プロンプトの一部)で絞り込める。`%` や `_` を含む語も、文字として検索される。
- [ ] 「名前を付けて保存」で任意の場所に保存できる。「フォルダで表示」でエクスプローラー / Finder が開き、ファイルが選択される。
- [ ] 削除 → 確認ダイアログ → **OS のゴミ箱**に入る(完全削除されない)。一覧から消える。
- [ ] 複数選択(Ctrl/⌘/Shift クリック)で、一括お気に入り・一括削除ができる。
- [ ] 画像が 100 枚以上あっても、スクロールが滑らかで、末尾付近で続きが読み込まれる。

## 6. プリセット

- [ ] 生成画面で「プリセットとして保存」→ 名前入力 → 保存できる。同名は「上書き保存」と表示される。
- [ ] プリセットを適用すると、モデル・サイズ・ステップ・シードのランダム設定などが復元される。
- [ ] `/presets` で一覧・名前変更・削除(確認つき)・「生成画面で使う」ができる。

## 7. 設定

- [ ] テーマ(ライト / ダーク / システム)が即座に反映される。言語の切り替えが反映される。
- [ ] **保存先の変更(移動する)**: 別のフォルダを選び「移動する」→ ギャラリーの画像が引き続き表示される。旧フォルダのファイルがゴミ箱へ移っている。
- [ ] **保存先の変更(移動しない)**: 警告が表示され、実行すると既存画像は表示されなくなる。保存先を元に戻すと再び表示される。
- [ ] 生成中は保存先を変更できない(エラー表示)。
- [ ] 保存先に **日本語・空白を含むパス**を指定しても動作する。
- [ ] 「既定に戻す」が動作する。

## 8. 永続化・復旧

- [ ] アプリを終了して再起動 → ギャラリー、プリセット、設定、生成フォームの下書きが残っている。
- [ ] 生成中にアプリを強制終了して再起動 → そのジョブが「失敗(アプリの終了により中断)」になり、待機中のジョブは再開される。
- [ ] 旧バージョンの DB がある環境へ上書きインストール → データが引き継がれ、`gazoo.db.bak-<version>` が作られる(スキーマ更新があるリリースのみ)。

## 9. ショートカット

- [ ] `Ctrl/⌘ + 1〜5` で画面が切り替わる(ダイアログ表示中は切り替わらない)。
- [ ] `Esc` が、生成画面で実行中ジョブを取り消す。ダイアログやパネルを開いているときは、それらを閉じるだけでジョブは取り消されない。

## 10. Windows 固有

- [ ] ユーザー名が **日本語** のアカウントで、インストール・起動・生成・保存ができる。
- [ ] ComfyUI 公式ポータブル版(`http://127.0.0.1:8188`)に接続できる。
- [ ] ウイルス対策ソフトが有効な状態で、画像の保存・削除・移動が失敗しない(一時的なファイルロック)。
- [ ] 高 DPI(125% / 150%)で、レイアウトが崩れない。
- [ ] `npm run comfyui:setup` / `start`(PowerShell スクリプト)が動作する(開発者向け。未検証の項目)。

## 11. アンインストール

- [ ] Windows: 「設定 → アプリ」からアンインストールできる。macOS: `.app` を削除できる。
- [ ] ユーザーデータ(DB・画像)は残る(仕様)。再インストールすると引き継がれる。

## 開発中の実機検証ログ

リリース前の人間による検証(§1〜11)とは別に、開発中に実施した実機検証の記録。**画面操作は含まない**(アプリのウィンドウは目視していない)。

### 2026-11-19 — macOS(Apple M3、メモリ 16GB)/ ComfyUI 0.45.6 / SD 1.5(`v1-5-pruned-emaonly.safetensors`、SHA-256 照合済み)

`cd src-tauri && cargo test --locked -- --ignored real_comfyui --nocapture` の 7 件がすべて成功。

| 確認した内容 | 結果 |
|---|---|
| 接続・ヘルスチェック・モデル一覧・GGUF ノード検出(実機の応答形式の解釈) | ✅ |
| 存在しないモデルの投入が `ENGINE_MODEL_MISSING` に分類される(SD / Flux GGUF) | ✅ |
| 4 種類(SD1.5 / SDXL / Flux / Flux GGUF)のワークフローが、実機のバリデータに構造的に受理される | ✅ |
| SD 1.5 で実際に画像が生成される(512×512 の PNG、WebSocket の進捗 8/8) | ✅ |
| **同じシード → 画素が完全に一致**、別のシード → 別の画像(「この設定で生成」の前提) | ✅ |
| ジョブキュー経由で生成 → 画像と 384px のサムネイルが保存され、進捗が通知される | ✅ |
| 実行中のキャンセル(150 ステップ・768px の生成が約 0.1 秒で中断)→ 次のジョブが正常に完了 | ✅ |

未検証: SDXL・Flux の **実際の生成**(モデル未導入)、画面操作すべて、Windows すべて。

## 既知の制限(リリースノートに記載する)

- コード署名・公証なし(SmartScreen / Gatekeeper の警告)。
- アイコンは暫定(Tauri 既定)。
- 自動アップデートなし。
- 生成中のプレビュー画像、LoRA、img2img は未対応。
- 画像生成には別途 ComfyUI の起動とモデルの配置が必要(アプリは接続のみ)。
- AMD / Intel GPU(Windows)は検証対象外。
